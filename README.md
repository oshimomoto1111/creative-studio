# ATELIER VOID — Auteur Creative Studio

> **"We give form to what sleeps in the void."**  
> An independent creative atelier specializing in bespoke brand identity, commercial photography, and cinematic motion for luxury hospitality, high-performance athletic enterprises, and visionary brands.

---

## Concept & Visual Direction
* **The Metaphor:** The creative void and the singularity of light (*Ex Nihilo / Lux in Tenebris*).
* **Aesthetics:** Dark-mode dominant (`#050505`), obsidian surfaces, warm solar amber accents (`#E5A93C`), and editorial typography.
* **Sound Design:** Web Audio API real-time ambient cinematic drone synthesizer (55Hz / 110Hz sub-sine with lowpass filtering).

---

## Architectural Stack
* **Markup:** Semantic HTML5 with microdata and accessible modal dialogues.
* **Styles:** Native Modern CSS3 with registered `@property` custom properties for hardware-accelerated spotlight gradient tracking.
* **Motion & Physics:** 
  * Canvas-based gravitational particle field reacting to mouse inertia.
  * Interactive category-filtered portfolio grid (`All`, `Identity`, `Photography`, `Film`).
  * Case study modal dialog for deep-dive deliverables.
* **Audio:** Web Audio API dual-oscillator ambient sound engine.
