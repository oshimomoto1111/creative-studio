## Aesthetic & Architectural Synthesis

This website synthesizes the world-class craft of five benchmark design practices:

1. **PORTO ROCHA** (`portorocha.com`):
   - Real-time studio utility clock (`ALBUQUERQUE, NM // [HH:MM:SS MST]`).
   - Dual **Grid** `[::]` vs **Index** `[=]` archive view switcher.
   - Availability status pill (`● AVAILABLE FOR COMMISSIONS Q4 '26 / '27`).
2. **Pentagram** (`pentagram.com`):
   - Swiss typographic hierarchy and monumental editorial scale.
   - Work-first discipline and 4-column structured case study metadata.
3. **&Walsh** (`andwalsh.com`):
   - Kinetic hover reveals with a floating cursor preview card that lerps smoothly to mouse coordinates.
4. **Fuzzco** (`fuzzco.com`):
   - Intimate editorial storytelling in *The Culinary Spine*, connecting Oscar's 15+ years of executive kitchen leadership directly to design precision without corporate jargon.
5. **Anagrama** (`anagrama.com`):
   - Obsidian dark palette (`#08080a`, `#111114`), tactile chalk (`#f4f4f6`), and warm solar amber accents (`#e5a93c`).

## Technical Stack

- **Markup**: Semantic HTML5 with accessible top-layer `<dialog>` element and microdata.
- **CSS**: Modern CSS with discrete top-layer transitions (`@starting-style`, `transition-behavior: allow-discrete`), hardware-accelerated ambient cursor spotlight, and Tailwind utility foundations.
- **JavaScript Engine**:
  - Real-time Albuquerque MST studio clock (`America/Denver` Intl API).
  - Dual view toggle (Grid / Index).
  - Mouse lerp physics for cursor preview tooltip.
  - Interactive case study modal with project data registry.
  - Interactive commission inquiry form with scope chips.
  - Web Audio API warm polyphonic harmonic pad synthesizer.
